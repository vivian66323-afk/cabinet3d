3D渲染 — 自動送圖擴充功能系統櫃 3D 設計平台．Chrome 專用．選配

裝了這個擴充功能之後，設計平台上的「3D渲染」就會變成全自動：自動開新對話、 上傳控制圖、貼上提示詞、按下送出，你只要等圖。用的是 Gemini／ChatGPT 網頁的免費額度， 不需要 API 金鑰，也不會多收任何費用。

沒裝的話「3D渲染」照樣能用，只是最後一步要自己做。瀏覽器基於安全規定， 禁止一個網站去操作另一個網站（Gemini、ChatGPT）的頁面，所以全自動只能靠擴充功能完成。

安裝步驟（約 30 秒，每台電腦做一次）

  1. 按上面的「下載擴充功能」，然後解壓縮。會得到一個資料夾，裡面有 manifest.json。
    把它放在固定的位置（例如文件資料夾）， 之後不要刪掉或搬走，刪了擴充功能就失效。
  2. Chrome 網址列輸入 chrome://extensions 後按 Enter。
  3. 打開右上角的「開發人員模式」。
  4. 點左上角出現的「載入未封裝項目」，選剛才解壓縮出來的資料夾 （選資料夾本身，不要點進去選檔案）。
  5. 回到設計平台，按 Ctrl + F5 重新整理一次。
第一次使用前，請先在這個 Chrome 登入要用的服務： Gemini 用 Google 帳號、ChatGPT 用 OpenAI 帳號。登入一次之後就會記住。

怎麼用

  1. 在設計平台把視角轉到想出圖的角度。
  2. 按右上角「3D渲染」。
  3. 選「送到 Gemini 或 ChatGPT」、風格、燈光、家具。
  4. 按綠色的「送進 ○○ 並自動生圖」。

瀏覽器會自動切到該服務的分頁，右上角有進度提示；出圖完成後直接在那邊下載圖片。

常見問題

面板上沒出現綠色的「送進 ○○ 並自動生圖」
裝完後要按 Ctrl + F5 重新整理設計平台。還是沒有的話，到 chrome://extensions 確認這個擴充功能是開啟狀態。
它說「找不到輸入框」或「找不到檔案上傳欄」
Gemini／ChatGPT 改版了，網頁的欄位換了位置。請回報給我們更新， 更新後重新下載安裝即可。
ChatGPT 說「你可以傳送最多 2 個檔案」
不會發生。送 ChatGPT 時系統只會送「視角＋線稿」兩張，提示詞也會自動調整。
ChatGPT 回「這邊發生錯誤，因此無法生成圖片」
多半是 ChatGPT 免費版當天的出圖額度用完了（每天約 4 張），它不會明說。 改用 Gemini，或隔天再試。
Chrome 每次開機都問「要停用開發人員模式的擴充功能嗎」
這是未上架 Chrome 線上應用程式商店的擴充功能的正常提醒，選「保留」即可。
我的資料會被傳到哪裡？
只會傳到你自己選的 Gemini 或 ChatGPT 分頁，用你自己的帳號。 這個擴充功能沒有自己的伺服器，不會蒐集或外傳任何東西。
